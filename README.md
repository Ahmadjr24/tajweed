# أحكام التجويد برواية حفص · Tajwīd rules

An interactive app for learning the tajwīd rules of the narration of Ḥafṣ from ʿĀṣim (by way of the Shāṭibiyyah), in Arabic, English and Danish.

Open it: https://ahmadjr24.github.io/tajweed/

Recitation by Sheikh Mishary Rashid Alafasy; word timings from Quran.com.
